# Практична робота 6 — Smart Grid

Варіант 8: система розподілу електроенергії. ПІБ: __________. Група: __________. Репозиторій: __________.

Навчальні вузли мають поточне навантаження loadMw і номінальну потужність capacityMw, координати, тип і час. E = P × t: МВт × год = МВт·год. Порогове навантаження є умовним параметром демонстрації. Датчики телефона не вимірюють параметри електромережі.

Вхід: operator@demo.ua або viewer@demo.ua, пароль Demo12345. `./gradlew assembleDebug testDebugUnitTest`. Потрібні JDK 17 та Android SDK 35, Build Tools 36.

Документація: docs/DEFENSE.md, docs/REQUIREMENTS.md. Проєкти нарощують можливості від PW01 до PW06; BuildConfig.PRACTICAL обмежує доступні екрани.
